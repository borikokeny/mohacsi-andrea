# Hidak Önmagunkhoz

Hivatalos weboldal:
https://mohacsiandrea.hu

A honlap célja, hogy bemutassa Mohácsi Andrea integratív szemléletű mentálhigiénés tevékenységét, az egyéni és csoportos önismereti lehetőségeket, valamint az aktuális programokat.

## Technológiák

- React
- TypeScript
- Vite
- React Router
- Tailwind CSS
- Font Awesome

## Fejlesztői környezet

A projekt futtatása:

```bash
npm install
npm run dev
```

Fejlesztői szerver:

```
http://localhost:5173
```

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```
